# Export Rules

## Current Visible View

Exports only the active page’s displayed state:

- active filters
- search results
- sort order
- visible rows
- selected row highlight
- visible cards/charts/KPIs where applicable

Excel must start from the actual table header row and should not include website header blocks, portal metadata, reporting basis rows, generated timestamp rows, or blank spacer rows.

## Page-wise / Current Page Full Data

Exports one selected report page at a time. This must not trigger whole-portal export.

## All Visible Portal Pages

Combined all-page export belongs only under the Data Export tab’s All Visible Portal Pages section.

## History Compare

Exports the selected From Sync / To Sync comparison with current comparison filters/sort.

## Formatting standards

Excel:

- editable `.xlsx`
- Times New Roman table font
- black borders
- fitted columns
- wrapped text
- landscape setup where wide
- freeze header row where useful

PDF:

- professional report layout
- readable Times New Roman or closest available font
- safe margins
- repeated headers
- no cut-off tables/charts

PowerPoint:

- editable where possible
- professional slide layout
- no oversized table forced into one slide
- no repair/corruption prompt
